## What's new

- Layer rows always show the eye, the lock and the menu in fixed places, so hiding or locking is one click. The eye is bright when a layer is shown and greyed out when it is hidden; the lock is bright when locked.
- New **Apply to all labels** button in the text label inspector: every label of the selected kind takes its font, size, colour and bold, italic and underline.
- Black or very dark label text turns light on the Dark and Blue drawing backgrounds, and very light text turns dark on the Light one. This covers text labels and area labels, including those from imported .axf files.
- Ctrl+click adds a label or symbol to the selection and removes it again on a second Ctrl+click.
- The angle snap setting (Off, 5, 15, 45, 90 degrees) now controls drawing. It was fixed at 5 degrees, and Off had no effect.
- Arrow keys nudge a selection by the snap pitch (Shift moves ten pitches); with snap off they still move 1 ft.
- Layers paint in list order: a layer's walls no longer cover the areas of the layers above it.
- Open and Save dialogs run on their own thread (from 0.3.4).

## Windows

Run **SketchRust-0.3.5-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
