## What's new

- Delete a wall from a closed area, then draw it again: the area comes back with its type, name and settings, including areas whose walls other areas touch (it used to stay open for areas like a main floor with a garage beside it).
- The Areas list now shows every layer, including ones left behind by a deleted or reopened area, so they no longer hide.
- Delete from the list: a row's menu has **Delete area** (the area, its walls and its layer) or **Delete layer** (the layer and everything on it, as one Undo step; the last layer is kept). A folder's menu deletes the folder and keeps what was inside.
- Removed Export from the layer row menu.

## Windows

Run **SketchRust-0.3.6-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
