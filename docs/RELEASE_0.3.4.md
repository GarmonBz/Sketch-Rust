## What's new

- Fixed the Open and Save dialogs hanging on "Working on it..." when they showed the Downloads folder. They now run on a thread of their own, so a slow folder no longer freezes them or the window behind.

## Windows

Run **SketchRust-0.3.4-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
