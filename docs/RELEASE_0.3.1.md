## What's new

- New **Door Garage 216** symbol in Doors & windows: a double garage door 18 ft (216 in) wide, made from the CADdillo 108-inch garage door. It replaces the older Favorites symbol Door - Garage-Dbl; sketches that used the old symbol open with the new one.
- Fixed the selection box, corner handles and rotation handle on symbols whose origin is not at the middle of the symbol, such as doors and windows. They were drawn offset from the symbol.
- Symbols draw in light ink on the Dark and Blue drawing backgrounds, with closed shapes filled in the canvas color.

## Windows

Run **SketchRust-0.3.1-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
