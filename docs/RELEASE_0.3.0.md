## What's new

- The Areas panel gives Layers more room by default, and the divider between Areas and Layers can be dragged.
- Page tabs are replaced by a page switcher in the top bar: previous and next buttons, the page name with its number, a page menu and an add button. It fits at any window width.
- The right-click canvas menu closes when you click the canvas or press Escape.
- Choosing an area type renames a default area name to match; a name you typed is kept.
- Default area types: GBA5 to GBA10 are removed and the Carport code is now CPT. Saved sketches are not changed.
- Interface theme and drawing background selectors both list Light, Blue, Dark.
- Snap applies when dragging wall ends and area corners and when moving selections.
- The Select more pill only appears in touch mode.
- The default symbol library no longer includes the Arrows, Doors, Windows and Miscellaneous categories (73 symbols). Doors & windows stays. Sketches that used a removed symbol no longer draw it.

## Windows

Run **SketchRust-0.3.0-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
