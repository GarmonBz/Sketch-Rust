## What's new

- Restored **Freeform** and **Erase** in the tool tray and command search.
- Freeform draws unsnapped lines without dimensions or wall solids. Strokes are saved and included in printed and exported sketches.
- Erase supports clicking or dragging across lines, room labels, and symbols. It respects hidden and locked layers.
- Each drawing or erasing gesture is one Undo step (**Ctrl+Z**). Both tools support mouse and touch input.

## Windows

Run **SketchRust-0.2.8-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP is also provided. Each download includes a `.sha256` checksum file.
