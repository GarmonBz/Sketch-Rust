Subject: Native desktop sketch-provider integration with Appraise-It Pro

We are developing Sketch Rust, a native Windows property sketching application,
and want to integrate it with Appraise-It Pro like Apex Sketch v7: launch from
Pro, edit a report-linked sketch, return sketch pages and calculated areas, and
reopen the editable sketch later. Both older fixed-form reports (including 1004)
and dynamic UAD 3.6 reports are required. We are not seeking the HTML/web portal
integration. The installed Pro integration assemblies are version 3.8.8.0.

We have reviewed your published COM/.NET APIs, including IntegrationClient,
TransferSketchData and the SketchAndAreaDataClient/SketchDataClient types.
TransferSketchData is documented as supporting dynamic/UAD 3.6 reports only.

Could you provide the supported desktop sketch-provider registration/launch SDK
or configuration used to add an independent sketch program to Pro, plus:

1. Launch arguments, report/process/session identity, and cancellation/lifetime
   rules for a report-linked sketch session.
2. The supported legacy sketch/image/area exchange contract, classification and
   field/addendum mappings, accepted formats, and update/reopen behavior.
3. The UAD 3.6 rules for associating sketches and levels with the correct
   property, structure, unit and outbuilding, and supported image formats.
4. The recommended way to retain/retrieve our editable sketch data in the
   report, and minimum supported Pro/API versions.
5. Any partner registration requirements and example native sketch integration.

The integration should coexist with Apex, Sketch-It and Sketch32. We do not
intend to replace their executables or use undocumented report-file edits.
