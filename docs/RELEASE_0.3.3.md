## What's new

- Every row in the Areas and layers list has a grab handle on the left, so it is clear that rows can be dragged up or down, or onto a folder.
- Area labels: Bold now works. The label name starts bold, and turning Bold off, or on, sticks. The Bold button shows the real state, and exported images and PDFs follow it.
- Save As Sketchie no longer stops with an error about draft 0.1 workfiles. Sketchie 0.2 is the only Sketchie version Sketch Rust opens and saves; draft 0.1 files are no longer supported.
- Fallingwater, a full multi-page example sketch, is included with the installer and the portable ZIP (`fallingwater.sketchie` in the install folder).

## Windows

Run **SketchRust-0.3.3-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
