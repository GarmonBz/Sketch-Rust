## What's new

- Areas and Layers are now one list. Each area shows its name with its type and size on a second line, so long names are not squeezed.
- Every row has an eye to hide it. The lock and the row menu appear when you point at a row; touch screens keep the eye and the menu.
- Layer folders group areas and layers. Hide or lock a folder to hide or lock everything inside it. The folder button beside the Areas menu adds one, and a folder's menu can delete it (what is inside moves up).
- Drag any row up or down to change the order, or onto a folder to move it inside. In a row's menu, Move to layer sends an area to another folder, and Top level takes it back out.
- Click an area to select it and see its numbers. Clicking no longer changes which layer new work is drawn on.
- The separate Layers section, its divider and the Layers tab are gone, along with the Show layers section menu entry.
- Legacy .axf sketches now open (File > Open, drag and drop, or double-click) as a converted new sketch with their areas, arc walls and room labels; Save As keeps it as .sketchie. Doors and fixtures are not imported yet.

## Windows

Run **SketchRust-0.3.2-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
