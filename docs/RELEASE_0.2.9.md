## What's new

- Fixed the tool tray overlapping Grid, Snap, Show, and Dimensions.
- The tray and drawing controls now reserve space in one shared dock. When the canvas is too narrow, Zoom and drawing controls move to separate rows at the top.
- Placement accounts for the sidebar, inspector, touch density, and logical window width at Windows display scaling settings.
- Drawing popovers follow their control rows. Tool flyouts follow the selected tool and stay within the canvas, including after scrolling the tray.
- Freeform and Erase remain available in the tray and command search.

## Windows

Run **SketchRust-0.2.9-x64.msi** to install or upgrade Sketch Rust for the current Windows user. A portable ZIP and SHA-256 checksums are also provided.
